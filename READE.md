# FinSight Analytics

FinSight Analytics is a Flask + MySQL business analytics dashboard.

## Features

- Dashboard
- Sales Analytics
- Customer Analytics
- Product Analytics
- Interactive Charts
- Business KPIs
- Responsive UI

## Technology

- Python
- Flask
- MySQL
- Bootstrap
- Chart.js
- Pandas

## Installation

```bash
git clone https://github.com/yourusername/FinSight-Analytics.git

cd FinSight-Analytics

pip install -r requirements.txt
```

Create the database:

```sql
SOURCE database.sql;
```

Run the application:

```bash
python app.py
```

Visit:

```
http://127.0.0.1:5000
```
